# Employee Workforce Analytics & Interactive Dashboard

## 📊 Project Overview

An end-to-end Data Analytics case study developed during my Data Analyst
Internship at Swynex Technologies.

This project demonstrates the complete analytics workflow from data
cleaning and validation to exploratory analysis, SQL analysis,
interactive Power BI dashboard development, and business insights.

## 🎯 Objective

The objective of this project is to analyze employee workforce data
and understand workforce distribution, salary patterns, performance,
remote-work participation, and employee joining trends.

## 🛠️ Tools & Technologies

- Excel
- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- DAX

## 🔄 Project Workflow

Raw Data
→ Data Cleaning
→ Data Validation
→ Exploratory Data Analysis
→ SQL Analysis
→ Power BI Dashboard
→ Business Insights

## 📌 Dataset

- Records: 1,020
- Columns: 11
- Salary Range: $50,047.32 – $119,971.65
- Average Salary: $85,175.82

## 📈 Dashboard

The Power BI dashboard includes:

- Total Employees
- Average Salary
- Remote Employees
- Latest Join Year
- Employees by Department
- Performance Distribution
- Employee Joining Trend
- Remote Work Distribution
- Salary Distribution
- Interactive Filters

## 💡 Key Insights

- Devops has the highest employee count with 189 employees.
- California has the highest workforce representation with 187 employees.
- Average salary is $85,175.82.
- Good is the largest performance category with 270 employees.
- 513 employees are recorded as remote.
- Employee joining peaked in 2023 with 228 employees.

## ⚠️ Data Limitations

The dataset does not include information about employee turnover,
experience, promotions, satisfaction, or reasons behind performance
and remote-work classifications.
